# 极简日记模板设计

## 目标

把现有个人博客改为安静、极简的单栏日记本。首页以按日期倒序的文章信息流为主；文章页优先保证 Kindle、手机和桌面端的长文阅读体验。

## 页面结构

- 页头只保留站点名称与“首页、文章、关于”导航。
- 首页保留不超过两行的日记本介绍，随后直接展示文章列表。
- 列表条目显示日期、标题、摘要和可选标签；不用卡片、阴影、双栏或悬浮动画。
- 文章页显示日期、标题、摘要和正文；不增加评论、搜索或新的内容模型。

## 视觉与排版

- 使用暖白背景、深灰文字和低对比度分隔线。
- 内容区域采用单栏，文章正文最大宽度约 680px。
- 正文优先使用可用的中文衬线字体，移动端保持约 19px 的正文字号与约 1.9 的行距。
- 标题与元信息层级清晰，但视觉保持克制；不新增图片、图标或装饰性资产。

## 实现范围

调整现有 Astro 布局、首页、文章列表组件和文章详情样式。继续使用现有 Markdown 内容、Decap CMS、GitHub 仓库与 Cloudflare Pages 部署链路。

## 验证

安装锁定依赖后运行生产构建，确认首页、文章列表和全文页都能正常生成；随后在本地浏览器检查桌面与窄屏排版。
